= ADR-0005: Grounding review and disclaimer
:status: Accepted
:date: 2026-11-13
:deciders: Project author
:tags: agent, safety

== Context

Clinical facts (indications, contraindications, doses, thresholds, interactions)
must come only from retrieved evidence or tool output, never from the model's
own knowledge. The assignment requires a review step that flags unsupported or
clinically ambiguous claims before the final answer, and every answer must carry
an explicit medical disclaimer.

== Decision

Grounding is enforced twice:

* A separate `Reviewer` LLM call audits each draft claim against its cited
  evidence and tool output, producing a `Review` with a verdict
  (`pass`, `revise`, `insufficient_evidence`), unsupported claims and ambiguity
  flags.
* Deterministic code in `review.py` checks that every number in a claim appears
  verbatim in the cited text (except numbers taken from the user's question),
  so a hallucinated dose or threshold cannot pass even if the LLM reviewer
  misses it.

The `Answerer` then drops or softens unsupported claims, maps each surviving
claim to a `[Sx]` citation, and appends `MEDICAL_DISCLAIMER` (from
`backend/app/core/constants.py`) by code, so the disclaimer is never dependent
on the model.

== Alternatives considered

[cols="2,3,3",options="header"]
|===
| Option | Why considered | Why not chosen
| Trust the draft | Fewest LLM calls | No grounding guarantee; clinical facts could be hallucinated.
| LLM review only | Semantic judgment | A model can still miss a fabricated number; deterministic checks are needed.
| Deterministic checks only | Cheap and reliable for numbers | Cannot judge clinical ambiguity or whether a paraphrase is supported.
|===

== Pros

* Unsupported numbers are caught deterministically regardless of model quality.
* The critic is a separate call, so it is not contaminated by the drafting
  prompt's goals.
* The disclaimer is injected by code and therefore always present.

== Cons

* One extra LLM call per request adds latency and cost.
* The numeric check is conservative: it only validates numbers, not paraphrased
  qualitative claims.

== Trade-offs

Latency was traded for grounding. The reviewer and the deterministic check
together bound the risk of fabricated clinical facts, which is the product's
core safety property.

== Consequences and revisit triggers

Revisit if the numeric check produces too many false positives on legitimate
paraphrases, or if a stronger entailment model becomes available.
